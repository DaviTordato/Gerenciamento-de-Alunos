Explicação básica sobre cada request:

GET para listar todos os alunos:
localhost:3000/alunos 

GET para um aluno só:
localhost:3000/alunos/ID_DO_ALUNO

POST para adicionar registro de aluno:
localhost:3000/alunos

PUT para atualizar aluno:
localhost:3000/Alunos/ID_DO_ALUNO

DELETE para deletar registro de aluno:
localhost:3000/alunos/ID_DO_ALUNO
